# 形态卡：三维国漫（PBR 次世代 + 后期描边）

上层选择、构成差异与跨阶段责任见 [production-form-profiles.md](../production-form-profiles.md)。
本卡回答：选了这个形态之后，可执行文本本身变成什么样。示例均为合成改写。

本形态是「风格化三维」与「国漫二次元」的**已固化命名混合**：模型、材质与光照走
PBR 次世代，边缘由后期描边层承担。它单独成卡是因为市场上已有稳定、高量的生产惯例，
但卡内仍须逐项声明各层 owner——本形态最贵的错误是**边缘被几何与描边两层同时决定**。

## 叙事职责

用**写实体量与二次元线条的双重语言**承担画面：PBR 的材质、次表面与光照让角色和物有
可信的重量与质感，描边与造型线提供情绪、风格与识别。它擅长高价值大场面（战斗、飞行、
变身、天地异象）和角色魅力展示，单帧信息密度高于普通三维；它不擅长低成本快速产出——
全 3D 资产管线，动画、特效与渲染都贵，是全套件单价最高的形态之一。

## 身份锚点载体

识别靠**模型拓扑 + 比例 + 材质分区**，描边只承担风格统一，不承担区分度。PBR 写实材质
会把不同角色拉平（磨皮后更是同脸），所以结构差异必须写在**模型拓扑层**：脸模、头身比、
骨架肩宽、材质分区位置，逐条枚举到能把同组角色两两分开为止——和国漫二次元一样，
「清冷」「俊美」这类妆造词不构成锚点。瞳色与高光形状沿用精修国漫的规则：瞳色分层、
高光形状是识别锚点，不是装饰，且不许被氛围色吃掉。

## 连续性载体

- **必须传递**：模型比例与材质分区、描边权重与线色（哪些材质吃线、哪些不吃）、
  皮肤 SSS 值、瞳色与高光形状、光源方向与体积介质、接触点。
- **可以省**：逐帧次要形变、观众看不到的背面。
- **最常断裂处**：描边权重逐镜漂移（暗部重、亮部被高光吃掉）、PBR 高光把线冲断、
  瞳色高光形状变化、材质质感跳变（同一人这镜是皮下一镜是塑料）。

## 层级拆分

- 身份层：模型、比例、材质分区（PBR）；
- 环境层：场景几何、地面高度、可通行路径、遮挡体；
- 可动层：角色动作、道具物理响应、摄影机；
- 效果层：体积光、粒子、灵力/异象特效、景深、分级；
- **描边层：后期合成的二次元线层，唯一拥有边缘规则**。

硬规则：模型几何的边缘与描边层**不得同时决定同一根线**——几何负责结构，描边负责风格，
归属一旦混了，线会抖且改不动。描边规则（线宽、线色、亮度阈值、哪些材质不吃线）由
comp 层唯一写入，模型层不因描边需求改拓扑。效果层的氛围色可以盖环境层，盖到身份层时
必须保留瞳色与发色的可识别性。

## 光与材质词汇

可执行词汇是**表面如何响应光 + 线如何避让光**：皮肤次表面透光、布料粗糙分区、金属
高光是拉长条、描边在暗部重亮部轻、高光区线自动减淡、边缘轮廓光。写「湿布料上拉长的
高光条 + 肩线描边在轮廓光下隐去」可执行，「电影级」「次世代质感」不可执行。接触与
重量词汇与风格化三维相同：落脚下沉、被压出的形变、碰撞余势——这些比「流畅自然」
更可验证。

## 运动预算

默认可以全动作，但**动画、特效与渲染都贵，是全套件单价最高的运动层**。分配原则：
全动作只给高价值场面——战斗连招、飞行、变身、大招、情绪转折的出手；对白与走位镜
用完整口型加局部循环（衣摆、发梢、呼吸）撑住，这是行业常态；长距离位移与转身交给
剪辑承接。摄影机昂贵且必须有机：跟随、揭示、施压，不为炫技做连续长镜。特效（灵力、
异象）作为效果层单独预算，不挤占角色动作预算。

## 声音与文字职责

接触即有声：落地、放置、碰撞、摩擦都要有对应声源，缺失会让 PBR 的重量感垮掉。
通常做完整口型，需在形态卡里确认，它决定台词长度与画外比例。灵力/法术需要与画面
节奏对齐的声音符号（蓄力、释放、命中）。可读文字若是场景内几何体（牌匾、碑文、
屏幕），走资产 text policy，并声明是贴图还是后期层。

## 跨阶段传递

| 阶段 | 这个形态额外要写的 |
|---|---|
| develop | 描边规则的归属声明、全动作预算给哪类镜头、特效预算上限、模型拓扑差异化设计 |
| assets | 模型比例与材质分区、拓扑级结构差异清单、rig 姿势边界、描边吃线/不吃线清单 |
| image-prompts | 单帧的比例、材质响应、描边权重、瞳色与高光形状、摄影机空间 |
| storyboard | 轴线、机位高度、接触点起止、哪些镜进全动作预算、特效层的时机 |
| video-prompts | 接触事件与重量结果、摄影机动机与速度、描边随光的避让、特效层节奏 |
| review | 描边权重是否逐镜一致、材质质感是否跳变、角色是否拓扑级趋同、双 owner 是否串线 |

## 常见失效

- 描边权重逐镜漂移，或 PBR 高光把线冲断——连续性最常断处；
- 磨皮把结构差异抹平，角色同脸——差异必须下放到模型拓扑层；
- 材质质感跳变，同一角色这镜皮下一镜塑料；
- 模型几何和描边层都管边缘，线抖且改不动；
- 特效预算无上限，挤占角色动作与渲染；
- 把「电影级」「次世代质感」当规格写，整段没有一个可执行字段。
